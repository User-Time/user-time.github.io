## 准备工作

确保电脑上有一下软件：

- Python 3 [下载地址](https://www.python.org/downloads/)
- TXT _(不推荐)_ 或 VSCode [_下载地址_](https://code.visualstudio.com/) 或 Pycharm [_下载地址_](https://www.jetbrains.com/pycharm/download/?section=windows)
- Twinkle Tray(不要微软商店版本) [下载地址](https://twinkletray.com)
- 前往巴法云注册账号 [点击跳转](https://bemfa.com/)

## 巴法云

### 创建设备
 1. 点击TCP创客云
 2. 在右侧来填写 设备名+002   如: `monitor002`

*主题名字 后三位数字用来表示设备类型:*
`| 001  插座 | 002  灯泡 | 003  风扇 | 004  传感器 | 005  空调 | 006  开关 | 009  窗帘 |`

![创建设备](https://s1.imagehub.cc/images/2024/09/11/ddb956ec6a744d120fa4afb88658a17d.md.png)
### 修改昵称
1. 点击 设备卡片 左下角的昵称进行修改成 显示器，方便以后的使用以及小爱同学对设备的称呼。

## 代码部分
### 创建文件
首先创建一个文件夹，在里面创建一个文件命名为`Monitor.py`
### 编辑代码
将下面代码Copy到`Monitor.py`中
```python
import os
import socket
import subprocess
import threading
import time

uid = "52c849**************************"  # 此处填写32位巴法云私钥
device = "monitor002"  # 此处填写设备名


def connect_tcp():
    global tcp_socket
    tcp_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    server_ip = 'bemfa.com'
    server_port = 8344
    try:
        # 尝试连接服务器
        tcp_socket.connect((server_ip, server_port))
        # 发送订阅指令
        subscribe_command = f'cmd=1&uid={uid}&topic={device}\r\n'
        tcp_socket.send(subscribe_command.encode("utf-8"))
    except socket.error as e:
        print(f"连接失败: {e}")
        time.sleep(2)
        connect_tcp()


def send_heartbeat():
    try:
        # 发送心跳包
        heartbeat = 'ping\r\n'
        tcp_socket.send(heartbeat.encode("utf-8"))
    except socket.error as e:
        print(f"心跳发送失败: {e}")
        time.sleep(2)
        connect_tcp()
    # 每30秒发送一次心跳
    threading.Timer(30, send_heartbeat).start()


def adjust_monitor_brightness(cmd):
    username = os.environ['USERNAME']
    if "on" in cmd and cmd != "on":
        # 亮度调整命令
        brightness = cmd.split("#")[-1]
        command = (
                rf'"C:\Users\{username}\AppData\Local\Programs\twinkle-tray\Twinkle Tray.exe"'
                r' --MonitorNum=1 --Set=' + brightness
        )
    elif "off" in cmd:
        # 关闭显示器命令
        command = (
            rf'"C:\Users\{username}\AppData\Local\Programs\twinkle-tray\Twinkle Tray.exe"'
            r' --MonitorNum=1 --VCP=0xD6:5'
        )
    else:
        return

    try:
        # 执行命令
        with subprocess.Popen(command, shell=True, creationflags=subprocess.CREATE_NO_WINDOW) as process:
            process.wait()
    except subprocess.SubprocessError as e:
        print(f"命令执行失败: {e}")


connect_tcp()
send_heartbeat()

while True:
    try:
        # 接收服务器消息
        received_data = tcp_socket.recv(1024)
        if received_data:
            message = received_data.decode('utf-8')
            for segment in message.split("&"):
                if "msg" in segment:
                    status = segment[4:]
                    adjust_monitor_brightness(status)
                    break

            if "cmd=0" not in message:
                print('收到消息:', message)
        else:
            print("连接错误，重新连接")
            connect_tcp()
    except socket.error as e:
        print(f"接收数据时发生错误: {e}")
        time.sleep(3)

```
